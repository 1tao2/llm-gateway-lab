# 视频问题分类

问题记录格式：`一级分类 / 二级分类：可观察证据；影响或处理建议。`

| 一级分类 | 常见二级分类 | 判断依据 |
|---|---|---|
| 人物一致性 | 身份漂移、脸部变化、年龄/服装错误、多人串脸 | 与人物参考资产或镜间身份不一致 |
| 场景一致性 | 布局漂移、时代/地点错误、天气条件偏离、环境元素幻觉 | 与场景资产或 Prompt 环境约束不一致 |
| 道具一致性 | 缺失、形态/颜色错误、持有关系错误、凭空增减 | 与道具参考及人物交互不一致 |
| 动作与时序 | 动作未完成、顺序错误、瞬移、姿态突变、节奏不符 | 未遵循 Shot 或时间线描述 |
| 镜头与构图 | 景别、机位、运镜、轴线、主体位置错误 | 未遵循摄影和空间约束 |
| 物理与画面质量 | 穿模、肢体畸变、闪烁、融化、运动不连续 | 可见生成伪影或物理违和 |
| 音频与口型 | 台词错误、朗读标签、串词、漏词、口型不同步、音色漂移、无提示人声 | 与对白正文和声音策略不一致 |
| 文字与符号 | 错字、乱码、标识变形 | 画面中文字不可用或偏离资产 |
| 可靠性与性能 | 创建失败、超时、链接过期、耗时异常 | 接口或任务运行层面异常 |

严重度建议：

- `P0`：安全/合规事故或结果不可交付且造成外部影响。
- `P1`：核心人物、剧情、对白或场景错误，视频不可用。
- `P2`：明显瑕疵，需要重生成或编辑后才能使用。
- `P3`：轻微问题，不阻止当前用途。

示例：

```text
P2｜场景一致性 / 天气条件偏离：Prompt 未描述降雨，但视频出现持续雨线和湿地反光；改变原定环境氛围，建议重生成。
```
